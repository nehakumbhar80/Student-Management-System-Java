# 🎓 Student Management System (Java + MySQL)

A complete GUI-based Student Management System built using **Java Swing, JDBC, and MySQL**.

---

## 🚀 Features

* 👨‍🎓 Add Student Details
* 📚 Course Management
* 📝 Subject-wise Marks Entry
* 📅 Attendance Tracking
* 📊 View Data using SQL JOIN

---

## 🛠 Technologies Used

* Java (Swing)
* JDBC (Database Connectivity)
* MySQL (Database)

---

## ▶️ How to Run

1. Start XAMPP (MySQL)
2. Create database: `student_db`
3. Create required tables (Student, Course, Marks, Attendance)
4. Run `StudentFullGUI.java`
